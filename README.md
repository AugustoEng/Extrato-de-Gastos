## CRUD básico de inserção, listagem e soma de gastos
### Projeto básico para desenvolvimento de habilidades fundamentais em Python

Armazena os dados em um arquivo txt, "extrato.txt"

O script possui cinco funções dispostas no Menu:
- Ver extrato: Lista todos os gastos em lista e a soma do valor de todos eles
- Adicionar Gasto: Adiciona mais um gasto ao arquivo extrato.txt
- Remover Gasto: armazena as informações do extrato.txt na memória, exclui o elemento solicitado e sobrescreve o arquivo extrato.txt
- Sair: Fecha o programa
